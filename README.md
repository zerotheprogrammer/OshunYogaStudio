# Oshun Yoga Studio

A yoga studio website with Home, Classes, Schedule, Mythology,
and Contact pages.

## HTML and CSS References

The following resources explain the HTML elements and CSS techniques
included in this project.

### HTML

- [MDN — HTML Elements Reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements)
  Explains page structure, navigation, headings, links, images,
  and elements such as header, main, section, article, and footer.

- [MDN — HTML Tables](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/table)
  Explains the table, caption, rows, and header cells used
  for the class schedule.

- [MDN — HTML Forms](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/form)
  Provides documentation for the contact form and links to
  form controls such as inputs, labels, and buttons.

### CSS

- [MDN — CSS Properties](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties)
  Provides references for colors, fonts, spacing, borders,
  rounded corners, shadows, and image sizing.

- [MDN — CSS Flexbox](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Flexible_box_layout)
  Explains the flexible layouts used for navigation,
  buttons, and the footer.

- [MDN — CSS Grid](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Grid_layout)
  Explains the columns used for the home page, class cards,
  mythology page, and contact page.

- [MDN — CSS Custom Properties](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascading_variables/Using_custom_properties)
  Explains reusable color variables defined in :root
  and accessed with var().

- [MDN — Media Queries](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media)
  Explains how layouts change for tablet and phone screens.

- [MDN — clamp()](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/clamp)
  Explains how heading sizes adjust while staying within
  minimum and maximum sizes.

- [MDN — :focus-visible](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/:focus-visible)
  Explains the visible outline used when navigating
  links and form controls with a keyboard.
